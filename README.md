 Campus Slot Booking System Using Greedy Activity Selection Algorithm
 Project Overview
This project is designed to manage campus room and facility bookings efficiently using the **Greedy Activity Selection Algorithm**. It selects the maximum number of non-overlapping bookings based on their start and end times.

 Features:
- Book campus rooms and facilities.
- Manage booking start and end times.
- Avoid overlapping bookings.
- Select maximum compatible bookings.
- Display selected booking slots.

Algorithm:
1. Enter booking start and end times.
2. Sort bookings by finishing time.
3. Select the booking that finishes earliest.
4. Select the next booking if its start time is greater than or equal to the previous booking's end time.
5. Display all selected bookings.

Conclusion:
This project demonstrates how the Greedy Activity Selection Algorithm can efficiently manage campus bookings, prevent scheduling conflicts, and maximize facility usage.
